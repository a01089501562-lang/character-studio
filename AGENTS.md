# Character Studio project instructions

For requests to modify this project, read and apply [.agents/skills/character-studio-delivery/SKILL.md](.agents/skills/character-studio-delivery/SKILL.md).

The user's standing preference is: complete the requested work, validate it, commit the task changes, and push to the existing GitHub origin (normally main), without asking for routine confirmation again. Explicit instructions to avoid commit/push or to work locally override this default. This also applies to changes to project instructions and skills. Read-only questions do not require commits.

Keep unrelated changes, reference files, backups, and credentials out of task commits. Report delivery status in Korean.

When resuming deployment or authentication setup, read [HANDOFF.md](HANDOFF.md) for the latest checkpoint before taking action. Update it when the deployment state changes; never record passwords, secrets, tokens, or OAuth query strings.
