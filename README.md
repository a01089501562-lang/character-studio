# Character Studio

특성화고 2학년 대상, 태블릿 드로잉 50분 × 4차시 캐릭터 제작 실습 웹페이지입니다.

## 사용과 수정

- `index.html`: 수업 구성과 안내
- `app.js`: 차시별 지시, 체크리스트, 기획 노트 저장, 예시 확대
- `config.js`: 외부 제출처 설정
- `assets/`: 직접 제작한 SVG 예시 4종, 구조 가이드 4종, 빈 작품 시트
- `style.css`: 반응형 및 인쇄 스타일

빌드나 외부 라이브러리가 필요 없습니다. `node serve.cjs` 실행 후 http://localhost:4173 에서 확인합니다.

제출처를 준비한 뒤 `config.js`의 `submissionUrl`에 실제 HTTPS 주소를 입력하세요. Google Forms, 클래스룸, 학교 LMS 등 외부 제출 페이지를 연결합니다. 학생 작품을 이 사이트나 GitHub에 업로드하는 기능은 없습니다. 링크 클릭만으로 제출 완료를 표시하지 않습니다.

기획 노트와 체크 상태는 현재 브라우저의 localStorage에만 저장됩니다. 공유 기기 사용 후 ‘기획·체크리스트 초기화’를 사용하세요. 브라우저 저장이 차단되면 화면 안내가 표시됩니다.

## GitHub Pages

공개 저장소에 파일을 올리고 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. `.nojekyll`을 포함합니다. 사용자 사이트가 아닌 프로젝트 사이트의 상대경로를 지원합니다.

## 예시와 평가

루미는 이 자료를 위해 직접 제작한 2.5등신 SD 캐릭터입니다. 기본형, 인사, 달리기, 점프 및 구조 가이드를 제공합니다. `node make-assets.cjs`로 동일한 SVG를 다시 생성할 수 있습니다. 수업 자료와 예시의 복제·수정·교육 활용을 허용합니다.

수업 활동은 캐릭터 제작 실습을 위해 구성한 제안이며, 특정 국가 교육과정 성취기준의 원문이나 공식 평가 기준이 아닙니다. 자기점검은 특징 유지, 동작 다양성, 전달력, 선·색 정리, 저장 여부로 구성됩니다.

## 점검

`node --check app.js`, `node --check config.js`로 문법을 확인합니다. 브라우저에서 15개 체크, 메모 저장과 새로고침, 초기화 취소/확인, 가이드 4종 전환, 확대·닫기, 템플릿 다운로드, 인쇄, 제출처 미설정/설정 상태를 점검합니다.

## 3면도 확장 수업

기본형 다음에 정면·측면 연습(50분), 후면·3면도 완성(50분)을 진행하고 응용동작으로 이어집니다. turnaround.js와 turnaround.css는 1200 × 720 실습 캔버스를 제공하며 assets/turnaround.svg는 루미 3면도 예시입니다. 그림은 새로고침 시 사라지므로 PNG로 저장하세요. 안내선 표시 상태가 PNG에도 반영됩니다. 체크리스트는 총 18개입니다.
